No build step

Browsers, load TypeScript.

This page runs .ts files directly. A service worker erases the types as each file loads, using Amaro, the same stripper Node.js uses. No bundler, no compile step, no type checking.

Types are replaced with spaces, so line and column numbers in errors match your source. TypeScript-only runtime features such as enum are rejected, exactly as in Node's strip-only mode. Service workers need HTTPS or localhost.
